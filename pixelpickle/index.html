Pixel Pickle: Nonograms

Pixel Pickle is a nonogram (picross) puzzle: every row and column carries a list of clue numbers, and filling exactly those runs draws the hidden picture. The game's own line solver decides every cell of a puzzle before it is shown, so a board can always be finished without guessing.
